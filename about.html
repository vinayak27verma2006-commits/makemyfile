About MakeMyFile

Simple tools for everyday file tasks.

MakeMyFile is a browser-based utility website designed to make common image and PDF tasks quick and straightforward.

It provides tools for image compression, resizing, format conversion, signature resizing, JPG-to-PDF conversion, PDF compression, PDF merging and PDF page extraction.

Privacy-focused processing

Where supported by the tool, files are processed directly in your browser rather than being uploaded to a MakeMyFile server.

Our goal

MakeMyFile aims to provide useful, accessible file utilities without unnecessary complexity.
